# Bank Management System - Frontend

Modern React-based frontend for the Bank Management System.

## Features
- User authentication (Login/Register)
- Account dashboard with balance display
- Deposit, Withdraw, and Transfer operations
- Transaction history
- Responsive design
- Modern UI with gradient cards

## Setup

1. Install dependencies:
```bash
npm install
```

2. Configure environment:
```bash
cp .env.example .env
# Edit .env if your backend is not on localhost:5000
```

3. Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Build for Production

```bash
npm run build
```

The production build will be in the `dist/` folder.
